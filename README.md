             This is the frontend for[Book Quote Finder]
             (https://github.com/prasoonkandel/Book_quote)
             Its designed for writers,researchers,and anyone looking for a special quotes they remember partially.this application uses**semantic  search** to find the most relevent quotes from a large book quote database.

  ## Features
             *Search for relevent book quotes using semantic search
             *Finds quotes from book quotes database
             *finds quotes based on your mood
             *Discoves relevant quotes database 
             * Get information about specific quotes
             *Simple and responsive user interface
